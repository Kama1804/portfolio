## 💻 Running Locally

No build tools or package managers required. Simply open `index.html` in any modern web browser or serve it with a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
